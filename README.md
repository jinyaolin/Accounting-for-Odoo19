[![Odoo Version](https://img.shields.io/badge/Odoo-19.0-green.svg)](https://www.odoo.com)

台灣會計在地化模組，適用於 Odoo 19 社群版，符合台灣商業會計法及稅務法規，專為貿易公司設計。

## 功能概覽

| 功能 | 說明 |
|------|------|
| 台灣會計科目表 | 7 碼標準科目編碼（資產/負債/權益/收入/費用） |
| 現金管理 | 現金收入、支出、日記帳、日報表 |
| 電子發票 | B2B/B2C 自動偵測、載具管理、字軌管理 |
| 稅務管理 | 5% 營業稅、零稅率、免稅、五舍六入 |
| 加值稅申報 | 401/403/405 申報、媒體申報檔產生 |
| 財務報表 | 資產負債表、損益表（台灣格式） |
| 貿易會計 | 進出口、關稅、運費分攤、外幣評價 |

---

## 安裝需求

- Odoo 19 Community
- Python 3.11+
- PostgreSQL 14+
- 依賴模組：`account`, `base_vat`, `stock`, `purchase`, `sale`

## 安裝步驟

```bash
# 1. 將模組放到 custom_addons 目錄
cd /path/to/odoo19/custom_addons/
git clone https://github.com/jinyaolin/Accounting-for-Odoo19.git tw_accounting

# 2. 確認 odoo.conf 中 addons_path 包含 custom_addons
# addons_path = odoo/addons,odoo/odoo/addons,custom_addons

# 3. 重啟 Odoo 並在 Apps 中安裝 Taiwan Accounting Localization
python odoo/odoo-bin -c odoo.conf -d mydb -i tw_accounting

# 4. 更新模組（已有安裝時）
python odoo/odoo-bin -c odoo.conf -d mydb -u tw_accounting
```

## 功能說明

### 1. 台灣會計科目表

模組安裝時自動匯入台灣標準會計科目，遵循 7 碼編碼規則：

| 開頭 | 類別 | 範例 |
|------|------|------|
| 1 | 資產類 | 1110001 庫存現金、1110002 銀行存款 |
| 2 | 負債類 | 2110001 應付帳款、2210001 預收款項 |
| 3 | 權益類 | 3100000 股本、3200000 保留盈餘 |
| 4 | 收入類 | 4100000 銷貨收入、4200000 勞務收入 |
| 5 | 費用類 | 5100000 銷貨成本、5200000 薪資支出 |
| 6 | 稅費類 | 營業稅相關科目 |

在會計科目表單頁籤「台灣會計設定」可設定：
- **台灣科目編碼**（tw_account_code）：7 碼數字
- **台灣科目類別**（tw_account_type）：資產/負債/權益/收入/費用
- **可抵扣稅額**（tw_tax_deductible）：是否可抵扣營業稅
- **科目群組**（tw_account_group）：用於財務報表分類

### 2. 現金管理

#### 2.1 現金收入

**操作路徑**：會計 > 現金管理 > 現金收入

**狀態流程**：
```
草稿 (draft) → 已確認 (confirmed) → 已過帳 (posted)
  ↓                                      ↓
取消 (cancelled)                    產生會計分錄
```

**操作步驟**：
1. 點擊「新建」建立現金收入單
2. 填寫：收入日期、收入類型、金額、幣別、會計科目、支付方式
3. 點擊「確認」將狀態改為已確認
4. 點擊「過帳」系統自動建立會計分錄（借：科目、貸：現金）

**收入類型**：

| 類型 | 說明 |
|------|------|
| sales | 銷貨收入 |
| service | 服務收入 |
| refund | 退款收入 |
| other | 其他收入 |

**會計分錄邏輯**：
- 借方：選擇的會計科目（資產類）或現金科目（收入類）
- 貸方：現金科目（資產類）或選擇的會計科目（收入類）
- 系統自動搜尋「庫存現金」（tw_account_code = 1110001）作為現金科目

#### 2.2 現金支出

**操作路徑**：會計 > 現金管理 > 現金支出

**狀態流程**：
```
草稿 (draft) → 已提交 (submitted) → 已核准 (approved) → 已過帳 (posted)
  ↓                                                          ↓
取消 (cancelled)                                        產生會計分錄
```

**操作步驟**：
1. 建立支出單，填寫支出類型、金額、收款人等
2. 點擊「提交」送出審核
3. 主管點擊「核准」（系統自動記錄核准人和核准日期）
4. 點擊「過帳」建立會計分錄

**支出類型**：

| 類型 | 說明 |
|------|------|
| purchase | 採購付款 |
| expense | 費用支出 |
| salary | 薪資支出 |
| tax | 稅捐支出 |
| dividend | 股利支出 |
| other | 其他支出 |

#### 2.3 現金日記帳

**操作路徑**：會計 > 現金管理 > 現金日記帳

**功能**：
- 輸入期初金額，系統自動計算當日收入合計、支出合計、期末金額
- 顯示銀行存款餘額（從會計分錄計算）
- 可產生文字格式現金日報表

**計算公式**：
```
期末金額 = 期初金額 + 收入合計 - 支出合計
```

**限制**：同一天同一家公司只能建立一筆日記帳。

### 3. 電子發票系統

#### 3.1 B2B/B2C 自動偵測

系統根據客戶的統一編號自動判斷發票類型：

| 客戶有統編 | 發票類型 | 必填欄位 |
|-----------|---------|---------|
| 是 | 三聯式發票 (tw_triple) | 買方統編、買方名稱 |
| 否 | 二聯式發票 (tw_double) | 載具資訊 |

**偵測邏輯**：
1. 當發票選擇客戶時，系統檢查客戶是否設有統一編號（tw_vat）
2. 有統編 → `tw_invoice_type = 'tw_triple'`（B2B）
3. 無統編 → `tw_invoice_type = 'tw_double'`（B2C）
4. 系統自動帶入客戶的預設載具設定

#### 3.2 合作夥伴設定

在客戶資料頁籤「台灣發票設定」可設定：
- **統一編號**（tw_vat）：8 碼數字，系統自動驗證格式
- **預設載具類型**：不使用 / 手機條碼 / 自然人憑證 / 捐贈碼 / 每次詢問
- **預設載具號碼**：對應的載具號碼
- **預設捐贈單位**：選擇捐贈碼時的預設捐贈單位

#### 3.3 載具格式規則

| 載具類型 | 格式 | 範例 |
|---------|------|------|
| 手機條碼 | 開頭 `/`，共 8 碼 | /AB12345 |
| 自然人憑證 | 2 碼英文 + 14 碼數字，共 16 碼 | AB12345678901234 |
| 捐贈碼 | 7 碼數字 | 1234567 |

#### 3.4 發票字軌管理

**操作路徑**：會計 > 配置 > 發票字軌管理

- 每期（2 個月）需設定字軌前綴（2 碼英文）和起迄號碼
- 系統自動追蹤已用號碼數和剩餘數量
- 字軌用盡時自動標記（is_exhausted）
- 號碼範圍：1 ~ 99,999,999

### 4. 稅務管理

#### 4.1 稅率設定

| 類型 | 稅率 | 說明 |
|------|------|------|
| vat_5 | 5% | 應稅（一般營業稅） |
| vat_zero | 0% | 零稅率（適用出口） |
| vat_exempt | 免稅 | 免稅項目 |

#### 4.2 五舍六入規則

台灣特有的進位規則（tw_rounding_method = `five_six`）：
- 金額尾數 < 5：捨去
- 金額尾數 >= 6：進位
- 不同於一般數學的四捨五入

---

### 5. 加值稅申報

**操作路徑**：會計 > 報告 > 加值稅申報

| 申報類型 | 說明 |
|---------|------|
| 401 | 營業人銷售額與稅額申報書 |
| 403 | 營業人購買國外勞務申報書 |
| 405 | 營業人期末存貨申報書 |

**操作流程**：
```
建立申報 → 計算 (calculate) → 產生媒體申報檔 (generate_file) → 提交 (submit)
```

系統會自動從發票資料彙整銷售額、稅額等數據。

---

### 6. 財務報表

**操作路徑**：會計 > 報告 > 財務報表

#### 6.1 資產負債表
- 按台灣會計科目分類呈現（資產 / 負債 / 權益）
- 使用 tw_account_type 欄位分類
- 可設定隱藏科目層級

#### 6.2 損益表
- 收入 vs 費用
- 計算本期淨利/淨損
- 台灣 GAAP 格式

---

### 7. 貿易會計

| 功能 | 說明 |
|------|------|
| 外幣評價 | 自動計算未實現匯率差異，產生評價分錄 |
| 關稅計算 | 進口貨物關稅自動計算，依 HS Code 和貨物價值 |
| 運保費分攤 | 依數量比例分攤運費/保險費到各產品成本 |
| 出口退稅 | 零稅率出口退稅計算 |

## 重要注意事項

### 法規相關

1. **現金交易限額**：單筆現金交易不得超過 **100,000 TWD**（台灣法規）。超過限額請使用轉帳或支票，否則系統會拒絕儲存。
2. **統一編號格式**：必須為 **8 碼純數字**，非數字或長度不正確會被系統拒絕。
3. **發票字軌期間**：每期為 2 個月（1-2月、3-4月、5-6月、7-8月、9-10月、11-12月），每期需設定新的字軌前綴和號碼範圍。

### 操作相關

4. **現金支出需核准**：支出單必須經過 提交→核准 流程才能過帳，未核准直接過帳會報錯。
5. **過帳不可逆**：過帳後會建立正式會計分錄（account.move），如需修改請先取消。
6. **幣別選擇**：現金收入/支出的幣別預設為公司幣別，可手動切換為其他已啟用的幣別。
7. **日記帳唯一性**：同一天同一家公司只能有一筆現金日記帳。
8. **現金日記帳**：系統安裝時自動建立「現金日記帳」Journal（代碼 TWC），用於過帳。

### 系統相關

9. **模組依賴**：安裝前需確保 `account`、`base_vat`、`stock`、`purchase`、`sale` 模組已安裝。
10. **科目表匯入**：模組安裝時自動匯入台灣科目表，安裝後可在「會計 > 配置 > 會計科目」中查看和管理。
